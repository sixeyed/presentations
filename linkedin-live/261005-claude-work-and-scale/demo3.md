# Demo: Claude Desktop


Open Claude Desktop


## Projects and the browser

Open `Substack` project - show instructions:

> https://sixeyed.substack.com


New session:

```
can you see my latest post?
```

Claude may read it behind the scenes by checking the RSS feed. Ask for a proof-read using the browser:

```
these posts are 100% human content. can you check them all for typos - use the browser tool so I can see you're checking the right pages
```

Opens the in-app browser window and navigates. This is interactive - you could log in and Claude can navigate using your permissions.
